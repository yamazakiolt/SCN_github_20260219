# SCNシミュレーション
このプログラムは
### 抑制性神経伝達物質が概日時計の光同調と履歴効果に及ぼす影響の数理解析
のFigure作成用プログラムです。
論文のFigureの作成方法を以下に説明します。
## Figure3.1, Figure3.2
1. "phase_osci"へ移動します。
2. "phase_osci.py"と"phase_osci_LSA.py"を実行します
3. "phase_osci_results"と"phase_osci_LSA_results"が作成されます。
4. "Figure3_1.py"と"Figure3_2.py"を実行します。"phase_osci_results"内にFigure3_1.pngが、"phase_osci_LSA_results"内に"Figure3_2.png"が生成されます。
## Figure3.3, Figure3.4
1. "single_neuron"へ移動します。
2. "single_neuron.py"と"single_neuron_TTX.py"を実行します。
3. "results"フォルダが生成され、"Figure3_3.png"と"Figure3_4.png"が生成されます。
## Figure3.5, Figure3.6
1. "light"へ移動します。
2. "phase_shift.py"を実行すると"results"が作成され、"Figure3_5.png"が生成されます。
3. "light.py"を実行すると"results"が作成され、"Figure3_6(a).png"と"Figure3_6(b)(c).png"が生成されます。
## Figure3.7
1. "vip"へ移動します。
2. "Figure3_7.py"を実行すると"results"が作成され、"Figure3_7.png"が生成されます。
